# Changelog

## [0.1.0] - 2026-11-17

- Hindsight's first release: every coding-agent session on this machine in one place — browse by agent and project, full-text search (CJK and code substrings), read transcripts with tool calls and thinking, resume in your terminal, star, pin, export and clean up.
- Read-only MCP server `hindsight-mcp` and command-line `hindsight-cli` for agents.
- Windows first (Windows 10/11, x86_64 and ARM64); macOS and Linux builds ship too, with platform notes where they differ.
